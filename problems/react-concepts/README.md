# React Concepts: Interview Trivia Drill

_Format: rapid-fire conceptual questions, the "explain X" and "what does this print?" rounds that show up in phone screens and the first 10–15 minutes of an onsite React interview. No coding environment._

The questions come from the topics that recur across the GreatFrontEnd top-50 list, the sudheerj/reactjs-interview-questions handbook (Hooks and React 18/19 sections), react.dev ("You Might Not Need an Effect", "Preserving and Resetting State", "Queueing a Series of State Updates"), and r/reactjs threads on senior interviews. One point from those threads: most candidates who fail lose points on the basics, not on advanced topics.

## How to use this

1. Open [QUESTIONS.md](QUESTIONS.md). Do **one round at a time**.
2. Answer each question **out loud first, as if to an interviewer**, then type a short version under its `>` line. Aim for 2–4 sentences. In an interview, a crisp answer beats a long one.
3. Don't look anything up. If you don't know, write your best guess and mark it `?`. Guessing and then being corrected is what makes it stick.
4. When the round is done, tell Claude **"check round N"**. Claude grades each answer (✅ / 🟡 partial / ❌), explains what's missing, and asks follow-ups the way an interviewer would.
5. [ANSWER_KEY.md](ANSWER_KEY.md) is the reference. **Don't open it until a round has been graded.** Use it afterwards to review.

Timing: about 10–15 minutes per round. "Predict the output" questions should take under a minute each. If one takes longer, your mental model of that topic needs work, so note it.
